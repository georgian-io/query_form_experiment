# Comparing Traditional and LLM-based Search for Image Geolocation

|  |  |
|---|---|
| **Authors** | Albatool Wazzan, Stephen MacNeil, Richard Souvenir (Temple University) |
| **Venue / date** | arXiv:2401.10184 — v1 2024-01-18 (CHIIR 2024) |
| **Links** | [abs](https://arxiv.org/abs/2401.10184) · [pdf](https://arxiv.org/pdf/2401.10184) · local: `original.pdf` |
| **Type** | Peer-reviewed user study (n = 60) |

## Summary

A controlled 60-participant study comparing how people query traditional search vs an LLM-based
search assistant for image geolocation. Findings on query formulation:

- **LLM-condition users issued longer, more natural-language queries**: avg **6.06 terms vs 4.19**
  for traditional search (significant).
- LLM users ran **shorter sessions** (avg **1.04 queries vs 1.98**) — one elaborate query, not
  iterative refinement.
- On reformulation, traditional users **added terms**; LLM users **rephrased** the whole query.
- (Task aside: traditional-search users were *more accurate* at geolocation here.)

## Relevance to this study

The **peer-reviewed anchor** for the magnitude/direction claim in the reframed verbose wording. It
empirically establishes that querying *through* an LLM shifts phrasing toward longer, full-sentence,
natural-language form — the register our verbose condition models — without overclaiming a specific
automated-rewrite mechanism.

Bonus parallels: "traditional users add terms, LLM users rephrase" maps onto our paraphrase
(rephrase, same length) vs terse/verbose (length change) axis. And the +1.9-term jump (4.19→6.06) is
a *human-behavior* effect size to set against our synthetic verbose (~45–54 words), underscoring
that verbose sits at the **elaborate end**, not the median.

## Cite for
- Empirical evidence that LLM-mediated search produces longer, natural-language queries.
- Human effect size for query lengthening under LLM assistance.
